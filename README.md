# Аналитическая панель ФГИС УПЧ

Интерактивный прототип аналитической панели обращений граждан для сотрудников аппаратов
Уполномоченных по правам человека. Проект хакатона, кейс Аппарата Уполномоченного по правам
человека в Российской Федерации.

**Сайт:** https://upch-analytics.github.io/panel/

> Все данные демонстрационные, сгенерированы скриптом и не являются официальной статистикой.

## Локальный запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173/panel/

Сборка: `npm run build` (результат в `dist/`).

## Публикация

При каждом push в ветку `main` GitHub Actions собирает проект и публикует его на GitHub Pages
(`.github/workflows/deploy.yml`). В настройках репозитория: Settings → Pages → Source: GitHub Actions.

## Демонстрационные данные

Набор генерируется детерминированно (фиксированный seed), поэтому у всех одинаковые цифры:

```bash
npm run data
```

Скрипт `scripts/generate-data.mjs` пишет `public/data/demo.json`. Описание модели данных в `CLAUDE.md`.
Список субъектов, население и коды берутся из `scripts/regions-ref.mjs`.
Численность населения округлена и используется только для расчета на 10 000 жителей.

## Карта

Контуры 89 субъектов РФ лежат в `public/data/regions.geo.json` и не загружаются со сторонних сайтов.

**Источник:** данные © участники OpenStreetMap, лицензия
[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

- 85 субъектов: набор [timurkanaz/Russia_geojson_OSM](https://github.com/timurkanaz/Russia_geojson_OSM),
  файл `GeoJson's/Countries/Russia_regions.geojson` (выгрузка из OSM, admin_level 4).
- Донецкая Народная Республика, Луганская Народная Республика, Запорожская и Херсонская области:
  границы административных единиц из OSM через Nominatim (relation 71973, 71971, 71980, 71022).

Сборка: файлы объединены, контуры упрощены [mapshaper](https://github.com/mbloch/mapshaper)
(`-simplify 1.5% keep-shapes weighted -clean`), затем `npm run build:geo -- <файл>` проставляет
коды субъектов по справочнику и проверяет, что найдены все 89.

Проекция: коническая равновеликая Альберса с центральным меридианом 100° в.д.

## Правила «Регионы, требующие внимания»

Правила записаны в `src/data/rules.ts` (`THRESHOLDS`). Регион сравнивается со средним по России
за тот же период и по той же категории прав. Попадание в список означает основание для
дополнительного анализа, а не вывод о нарушении прав. Рост числа обращений сам по себе
сигналом не считается.

| Показатель | Средний уровень | Высокий уровень | Дополнительное условие |
|---|---|---|---|
| Доля просроченных | выше средней в 1,4 раза | в 1,6 раза | разница не меньше 1 п.п. |
| Доля повторных | выше средней в 1,3 раза | в 1,45 раза | разница не меньше 1,5 п.п. |
| Доля восстановленных прав | ниже средней: 0,75 от средней | 0,65 от средней | разница не меньше 5 п.п., не меньше 10 дел с установленным нарушением |

Регион оценивается, только если за период в нем не меньше 50 обращений: на малых числах доли
неустойчивы. Порядок в списке: сначала высокий уровень, затем самое сильное отклонение.

## Расчет показателей

- Доля просроченных: просрочено / поступило, только по обращениям с наступившим сроком ответа
  (30 дней). Обращения текущего месяца и поступившие после 20 числа прошлого месяца в долю не входят;
  в прошлогоднем периоде исключаются те же месяцы, чтобы сравнение было честным.
- Доля повторных: повторные / поступило.
- Доля восстановленных прав: права восстановлены / завершено с установленным нарушением.
- На 10 000 жителей: поступило × 10 / население в тыс. человек.
- Сравнение: тот же период годом ранее. Если текущий период заканчивается неполным месяцем
  (октябрь 2026 по 20 число), месяц прошлого года берется с той же долей (20/31).
- Охват: подключенные субъекты / все субъекты справочника. Доля обращений в системе оценивается
  по численности населения неподключенных субъектов.

## Правила рекомендаций на странице региона

Правила записаны в `src/data/rules.ts` (функция `recommendations`, пороги в `THRESHOLDS`).
Рекомендации формулируются как основание для дополнительной проверки и анализа.

| Правило | Уровень | Условие |
|---|---|---|
| Доля просроченных выше общероссийской | высокий / средний | как в списке «Регионы, требующие внимания» |
| Повышенная доля повторных | высокий / средний | как в списке «Регионы, требующие внимания» |
| Низкая доля восстановленных прав | высокий / средний | как в списке «Регионы, требующие внимания» |
| Рост обращений по категории прав | средний | рост к прошлому году от 25% и не меньше 15 обращений; не больше двух категорий; названы территории с наибольшим приростом |
| Рост повторных в категории | средний | доля повторных выросла на 5 п.п. и более, не меньше 15 повторных; одна категория с наибольшим ростом |
| Нагрузка на исполнителей | высокий / средний | незавершенных обращений на исполнителя в 2 / 1,5 раза больше среднего по России |
| Основная категория обращений | информационный | всегда, для ориентира |
| Отклонений не выявлено | информационный | если не сработало ни одно правило выше |

## Карточки обращений

Карточки строятся в браузере детерминированно из `demo.json` (`src/data/records.ts`): в каждой ячейке
«субъект × месяц × категория» ровно столько поступивших, просроченных, рассмотренных, повторных
и восстановленных обращений, сколько в наборе. Поэтому счетчики папок совпадают с показателями.
Номер обращения: `код субъекта-ГГММ-категория-порядковый номер`, например `38-2609-4-0013`.
Персональные данные не используются: заявитель обозначен обезличенным номером. Муниципальные
образования взяты из OpenStreetMap (тот же набор, что и контуры), для четырех новых субъектов
список задан вручную (`scripts/municipalities.json`).
