# Аналитическая панель ФГИС УПЧ (прототип для хакатона)

Веб-прототип аналитической панели обращений граждан для сотрудников аппаратов
Уполномоченных по правам человека. Все данные демонстрационные.
Публикуется на https://upch-analytics.github.io/panel/ (GitHub Pages, GitHub Actions).

## Команды

- `npm install`: зависимости.
- `npm run dev`: локально, http://localhost:5173/panel/
- `npm run build`: проверка типов и сборка в `dist/`.
- `npm run data`: пересобрать `public/data/demo.json` (детерминированно, seed в скрипте).
- `npm run build:geo -- <упрощенный.geojson>`: пересобрать контуры (см. README, «Карта»).

## Стек

React 19, TypeScript, Vite 8, Tailwind CSS 4 (тема в `src/index.css`, блок `@theme`),
react-router (HashRouter: адреса `#/region/38`), d3-geo и d3-zoom для карты, Recharts для графиков,
lucide-react для иконок. Шрифты Golos Text и Source Serif 4 подключены локально (`@fontsource`).
Серверной части нет: только статические JSON в `public/data/`.

## Структура

- `scripts/regions-ref.mjs`: справочник 89 субъектов (код, ISO, название, округ, население).
  Единственный источник списка субъектов: из него строятся и карта, и данные, и метрика охвата.
- `scripts/generate-data.mjs`: генератор демонстрационных данных → `public/data/demo.json`.
- `scripts/build-geo.mjs`: проставляет коды субъектов в контуры → `public/data/regions.geo.json`.
- `src/data/`: типы и загрузка (`load.tsx`), расчеты (`agg.ts`), периоды (`period.ts`),
  фильтры в адресе страницы (`filters.ts`), правила внимания и рекомендаций (`rules.ts`).
- `src/components/`: `Layout`, `FilterBar`, `KpiBand`, `RussiaMap`, `Charts`, `AttentionList`.
- `src/components/Layout.tsx`: боковое меню, верхняя панель, обработка ошибки загрузки.
- `src/pages/`: страницы разделов (`Overview.tsx`: главная и «Карта регионов»; `Placeholder.tsx`: разделы этапа 4).
- `design/directions/`: наброски этапа 1 (не входят в сборку).
- `DESIGN.md`: дизайн-система «Атлас», токены и правила.

## Данные (`public/data/demo.json`)

- `regions[]`: справочник + `connected` (подключен ли УПЧ субъекта к ФГИС), `executors`, `groups`.
- `cube[code]`: плоский массив по субъекту, индекс `(месяц * 7 + категория) * 6 + метрика`.
  Метрики: `rec` поступило, `over` просрочено, `done` рассмотрено, `viol` нарушение установлено,
  `rest` права восстановлены (из `viol`), `rep` повторные.
- Месяцы 2023-01..2026-10, октябрь 2026 неполный (по 20 число, `partialFraction`).
  Сравнение с прошлым годом: тот же период, октябрь 2025 берется с той же долей.
- Национальные и окружные значения считаются суммой по субъектам, отдельно не хранятся.
- Доли: просрочено = over/rec, повторные = rep/rec, права восстановлены = rest/viol.
- Субъекты без подключения (83, 17, 79, 95) не имеют `cube`: на карте «Нет данных».

## Карта

- Ключ сопоставления: код субъекта (`properties.code`), не название.
- Проекция: коническая равновеликая Альберса, `rotate([-100, 0])`, параллели 52 и 64.
  Чукотка не разрывается.
- Контуры: OpenStreetMap (ODbL), источник и способ сборки в README.

## Правила

- Интерфейс только на русском. Без буквы «ё». Без длинных тире: двоеточие, запятая или дефис.
- Цвета только через смысловые токены из `src/index.css` (`bg-surface`, `text-muted`...), без hex.
- Цвет 5-го класса шкалы карты (`map-5`) в интерфейсе не используется.
- Все пути к данным через `import.meta.env.BASE_URL`.
- Демонстрационный характер данных обозначен на каждой странице и в отчетах.
- Рекомендации формулировать как основания для проверки, не как вывод о нарушении прав.
